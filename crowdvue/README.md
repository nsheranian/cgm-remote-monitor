# CrowdVue MVP - Step 1

This directory contains the initial setup for the CrowdVue MVP. The goal is to provide a simple React application configured to use Firebase for authentication and Firestore for data storage.

## Getting Started
1. Install dependencies:
   ```bash
   npm install
   ```
2. Add your Firebase credentials in `src/firebase.js`.
3. Build or run the app with your preferred bundler or tooling.

The app currently renders a placeholder screen confirming that the project setup is complete.
